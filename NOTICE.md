# Правовая позиция проекта

Коротко: проект не трогал код Холста. Формат разобран по файлам, которые
Холст сам отдаёт пользователю и которые по его же соглашению принадлежат
пользователю.

## Как разобран формат

Источник — файл `.holst`, полученный штатной выгрузкой доски из интерфейса
Холста. Это ZIP с `data.json`: обычные данные, а не программа. Разбор состоял
в чтении собственного пользовательского контента и сверке того, какие поля
за что отвечают.

Что **не** делалось: не декомпилировался и не дизассемблировался код Сервиса,
не исследовались его алгоритмы, не обходились технические средства защиты,
не использовалось непубличное API.
