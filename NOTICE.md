# Правовая позиция проекта

Коротко: проект не трогал код Холста. Формат разобран по файлам, которые
Холст сам отдаёт пользователю и которые по его же соглашению принадлежат
пользователю.

## Как разобран формат

Источник — файл `.holst`, полученный штатной выгрузкой доски из интерфейса
Холста. Это ZIP с `data.json`: обычные данные, а не программа. Разбор состоял
в чтении собственного пользовательского контента и сверке того, какие поля
за что отвечают.

Что **не** делалось: не декомпилировался и не дизассемблировался код Сервиса,
не исследовались его алгоритмы, не обходились технические средства защиты,
не использовалось непубличное API.

## Заимствования

Проект использует материалы из открытого проекта
[holst-board](https://github.com/soloveev/holst-board) (Дмитрий Соловьёв),
распространяемого на тех же условиях CC BY-NC-SA 4.0:

- **`scripts/inter_widths.json`** — таблица ширин глифов Inter (Regular и SemiBold),
  взята без изменений. По ней считается перенос строк и `bounds` текстовых блоков.
- **Модель геометрии текста** — внутренний кегль 14, высота строки 21,
  `bounds.width = (width + 0.5) × textScale`, отсутствие `fontFamily` в штатной
  выгрузке. Всё это выверено им по PDF-экспорту доски, где страница равна кадру,
  а один пункт PDF — одной единице доски. Наши прежние значения (интерлиньяж 1,28,
  затем 1,45, средняя ширина глифа) были подгонкой на глаз; его замеры точнее.
- **Описания типов `flip-card` и `link`**, геометрия карточки ссылки, токены
  палитры Холста и алгоритм мини-markdown — переработаны под наш API.

Обратное заимствование тоже было: описания `arrow`, `drawing`, `group`, `file`,
`table` и часть правил вёрстки он взял из этого проекта и указал это в своём NOTICE.
