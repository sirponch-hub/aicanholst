# Доски Холст (.holst)

Создание и чтение файлов онлайн-доски Холст (holst.so). Формат разобран по
штатной выгрузке доски и подтверждён экспериментально: сгенерированный файл
открывается в Холсте со всеми объектами, связями и форматированием.

## Как работать

1. Уточни у пользователя структуру доски, если она не задана: какие блоки (кадры),
   что внутри, нужны ли связи между элементами.
2. Прочитай `references/layout.md` — там правила вёрстки кадров и типографики.
   Без них доска получится нечитаемой: это главный источник ошибок.
3. Скопируй `scripts/holst.py` в рабочую папку (или добавь `scripts/` в `sys.path`),
   напиши скрипт сборки и запусти его.
4. Проверь результат (см. «Проверка») и отдай `.holst` пользователю.

Пользователь открывает файл в Холсте через «восстановить доску из файла».
Импортированная доска получает префикс «Восстановлено» в названии — это нормально.

**Если пользователь прислал свою выгрузку и просит поправить — не пересобирай доску
генератором**, правь `data.json` точечно: иначе пропадут объекты, которых нет
в библиотеке, и его собственные изменения. Порядок — в `references/editing.md`.

## Файлы скилла

| Файл | Когда читать |
|---|---|
| `references/layout.md` | **Всегда перед вёрсткой** — правила кадров, кегля, автоподгонки, вставки картинок |
| `references/format.md` | Когда нужен объект, не покрытый библиотекой (таблицы, `cropTransform`), или разбор чужой выгрузки |
| `references/editing.md` | Когда правишь присланную пользователем доску, а не собираешь новую |
| `scripts/holst.py` | Библиотека сборки. Копировать в рабочую папку, не переписывать |
| `scripts/validate.py` | Проверка готового файла: схема + вместимость текста |
| `scripts/preview.py` | Рендер кадров в PNG, чтобы посмотреть композицию глазами |
| `examples/retro.py` | Рабочий пример: ретроспектива на три команды |

## Минимальный пример

```python
import sys; sys.path.insert(0, "путь/к/скиллу/scripts")
from holst import Board, fit_scale, RED, GREEN, BLUE, WHITE

W, H, PAD = 4800, 2700, 200
b = Board("Ретроспектива спринта")

f = b.slide(0, 0, "Что мешало нам в спринте")
title = "Что мешало нам в спринте"
ts = fit_scale(title, W - 2 * PAD, 285, 12.0, floor=6.0)
b.text(PAD, 110, title, scale=ts, width=int((W - 2 * PAD) / ts),
       halign="center", fixed_width=True, bold=True, parent=f)

cw = (W - 2 * PAD - 120) / 3
for j, (name, color) in enumerate([("Мешало", RED), ("Помогало", GREEN), ("Попробуем", BLUE)]):
    x = PAD + j * (cw + 60)
    b.shape(x, 700, cw, 190, name, fill=color, stroke=color, font_size=90, parent=f)
    b.shape(x, 890, cw, 1400, fill=WHITE, stroke=0xBFBFBF, parent=f)
    b.empty_grid(x + 40, 940, 2, 2, cw - 80, 1300, color=color, parent=f)

b.save("board.holst")
```

Полный пример с раскладкой на несколько кадров — в `examples/retro.py`.

## Что даёт библиотека

`Board(name)` — доска. Методы создания объектов возвращают dict, который можно
передавать как `parent=` или в `arrow_between`.

- **Кадры:** `slide(x, y, label)` — кадр 16:9 4800×2700 (базовая единица),
  `frame(x, y, w, h, label)` — произвольный.
- **Содержимое:** `sticker`, `text`, `shape` (`square`/`ellipse`/`basic-star`),
  `image`, `image_fit`, `file` (PDF), `link`, `stamp`, `drawing`, `group`.
- **Связи:** `arrow(x1, y1, x2, y2)`, `arrow_between(a, b)` — с привязкой к объектам.
- **Сетки:** `sticker_grid(...)`, `empty_grid(...)` — вписываются в заданную область.
- **Типографика:** `box_h(text, w, fs)` — сколько высоты нужно тексту (считай высоту
  полосы отсюда), `fit_scale(text, width, budget, start)` для `text`,
  `fit_fs(text, w, h, fs)` для `shape`, `grid_size(cols, rows, w, h)`.
- **Ссылки:** `shape(link=...)`, `text(link=...)`, `image(link_to=...)` — поле `linkTo`.
- **Чтение:** `load(path)` → data.json, `object_text(obj)` → плоский текст объекта.
- **Цвета:** `YELLOW GREEN BLUE PINK ORANGE PURPLE RED GRAY WHITE BLACK DARK_GRAY`,
  либо любой int `0xRRGGBB`.

## Проверка

Перед выдачей файла прогони **обе** проверки.

**1. Автоматическая.** Схема, ZIP без сжатия, вместимость текста, выход за кадр,
мелкий кегль:

```bash
python scripts/validate.py board.holst
python scripts/validate.py board.holst --edited   # если файл уже открывали в Холсте
```

Скрипт возвращает ненулевой код, если есть ошибки. Правь, пока не станет чисто.
Флаг `--edited` отключает проверку `bounds` у текста: редактор Холста пересчитывает
их по фактической ширине, и расхождение там норма, а не порча.

**2. Глазами.** Отрендерь несколько кадров и посмотри на композицию:

```bash
python scripts/preview.py board.holst preview/ 0 3 7
```

Смотри **не всю доску целиком, а отдельные кадры** — доска из сотни кадров в общем
плане нечитаема и ничего не покажет. Бери самые плотные: таблицы, канвасы, кадры
с длинным текстом и со схемами. Глазами проверяется то, что арифметика не ловит:
композиция и выключка (например, подпись, уехавшая от своей фигуры).

Помни, что самодельный рендер не переносит строки в фигурах и не центрирует текст
так, как Холст. В превью текст может торчать за край, хотя в Холсте всё в порядке;
на вместимость ориентируйся по `validate.py`, а глазами смотри композицию.

## Ограничения

- Формат не документирован официально и может измениться — при поломке сверься
  со свежей выгрузкой из Холста.
- Проект неофициальный, не связан с ООО «Холст». Скилл работает только с файлами
  выгрузки; к самому сервису и его API он не обращается.
- Таблицы (`table` / `table-cell`) библиотекой не покрыты: собирать вручную
  по образцу из существующей выгрузки, см. `references/format.md`.
- `image_fit` требует Pillow, `preview.py` — cairosvg. Остальное — только stdlib.
