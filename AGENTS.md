# AI can Holst — инструкция для агента

Репозиторий одновременно библиотека и скилл: корень репозитория **и есть**
директория скилла (`SKILL.md` в корне, рядом `scripts/`, `references/`,
`agents/`). Формат общий — [agentskills.io](https://agentskills.io), — поэтому
одна и та же папка работает и в Codex, и в Claude Code, и в приложении Claude.

## Команды

```bash
python3 -m unittest discover tests        # 63 теста, должны быть зелёными
python3 tools/audit.py input/*.holst      # сверка с эталонной выгрузкой Холста
python3 examples/retro.py                 # пример: ретроспектива на 4 кадра
python3 examples/elements.py              # стенд всех 21 типа объектов
python3 scripts/validate.py board.holst   # проверка готового файла
python3 tools/build_standalone.py dist/SKILL.md   # автономная версия скилла
```

Зависимостей нет: библиотека и валидатор — чистый stdlib Python 3.8+.
Pillow нужен только для `image_fit()`, cairosvg — для `preview.py`.

## Правила работы с этим кодом

**Геометрия выверена по реальным файлам, а не выведена из общих соображений.**
Числа в `scripts/holst.py` — интерлиньяж 1.5, `bounds.width = (width + 0.5) × textScale`,
высота блока кода `строки × 21 + 30`, допуск переноса 0.5% — получены сравнением
того, что мы записали, с тем, что Холст вернул после импорта. **Не правьте их
«на глаз»**: если число кажется странным, проверьте его обратным импортом, а не
рассуждением. Каждая такая константа снабжена комментарием с источником.

**После правок в `scripts/` или `references/` пересоберите автономную версию:**

```bash
python3 tools/build_standalone.py dist/SKILL.md
```

Иначе скилл, установленный одним файлом, разойдётся с репозиторием — это уже
случалось.

**Новый тип объекта добавляется только по эталону.** Положите выгрузку с этим
объектом в `input/`, посмотрите фактические поля, добавьте метод и проверьте
`tools/audit.py`. Угаданные поля Холст молча игнорирует, и объект не открывается.

**Проверка готового файла — обе:** `scripts/validate.py` (схема и вместимость)
и глаза (`scripts/preview.py board.holst out/ --all`). Арифметика не ловит
композицию, глаз не ловит переполнение.

## Что где лежит

| Путь | Что это |
|---|---|
| `SKILL.md` | Точка входа для агента: порядок работы, обзор API, проверки |
| `scripts/holst.py` | Библиотека сборки и чтения `.holst` |
| `scripts/inter_widths.json` | Метрика шрифта Inter — по ней считается перенос строк |
| `scripts/validate.py`, `scripts/preview.py` | Проверка и рендер |
| `references/` | Спецификация формата, правила вёрстки, правка чужих выгрузок |
| `agents/openai.yaml` | Метаданные для приложения Codex |
| `tools/` | Сверка с эталоном и сборка автономной версии |
| `input/` | Эталонные выгрузки из Холста (в git не коммитятся, кроме мелких) |

## Codex Web и другие среды без файловых скиллов

Скиллы читают Codex CLI, расширение для IDE и приложение Codex. Там, где
директория скилла недоступна — Codex Web, чат-интерфейсы, — используйте
автономную версию `dist/SKILL.md`: это один файл со вклеенной библиотекой,
его можно положить в целевой репозиторий или вставить в контекст целиком.

Если добавляете скилл в чужой репозиторий, кладите его в `.agents/skills/holst-board/`
и упомяните в `AGENTS.md` того репозитория — тогда агент найдёт его сам.
